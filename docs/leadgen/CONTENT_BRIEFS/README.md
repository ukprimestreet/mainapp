# Content briefs

One brief per approved landing page, written **before** the copy. `TEMPLATE.md` is the shape.

**There are no briefs yet, because no page has been approved.** A brief is only written for a `PAGE_QUEUE.csv` record that has reached `AWAITING_APPROVAL` and been authorised.

A brief exists to force a question that is easy to skip: *what can this page say that is true, useful, and specific to this service in this place?* If the brief cannot answer it with evidence, the page should not be built — the intent gets merged into a stronger page and the decision is recorded in the queue.

# SEO experiments

One entry per deliberate change made to test a hypothesis. No entries yet — nothing has been published, so there is nothing to measure and no experiment would mean anything.

**Rules for this log**

1. An entry is written **before** the change, with the hypothesis and the metric stated. Writing it afterwards turns a result into a story.
2. One variable at a time, or the result is uninterpretable.
3. Record the date applied, the date first measured, and the measurement window. Search results move slowly; a week is rarely enough.
4. **"Ranking improved" is not a result** without the query, the location setting, the date and the source.
5. A negative result is recorded and kept. Those are the valuable ones.
6. Never claim a page is ranking without checking ranking data, and never claim causation from a single page.

**Blocked:** Search Console is not verified, so there is no first-party impression, click or query data. Until it is, no experiment on this platform can be measured honestly.

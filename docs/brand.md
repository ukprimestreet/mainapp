# PrimeStreet brand system

**Rule:** yellow = PrimeStreet. Yellow shouts, black commands, white breathes. One yellow only; never introduce a second.

## Tokens (single source: `src/app/globals.css`)
| Token | Value | Use |
|---|---|---|
| `--prime-yellow` | `#FFD400` | CTAs, logo, highlights, active nav, badges. Chosen after checking it reads as electric (not mustard/gold) against black and white. |
| `--prime-yellow-hover` | `#FFE14D` | Hover on yellow buttons |
| `--prime-yellow-dark` | `#E6BF00` | Pressed/active only |
| `--prime-yellow-soft` | `#FFF6C2` | Tinted note backgrounds; never for text |
| `--prime-black` | `#0A0A0A` | Text, header, footer, premium sections |
| `--prime-charcoal` | `#1C1C1E` | Hover on black |
| `--prime-grey` | `#6B6B70` | Secondary text |
| `--prime-grey-light` | `#F4F4F5` | Section backgrounds |
| `--prime-border` | `#E4E4E7` | Borders |

Contrast: black on yellow ≈ 14:1 (AAA); yellow on black ≈ 14:1; grey on white ≈ 5.2:1 (AA). **Never yellow text on white.** Grey text is not used on black (use white/70+).

## Logo
- The wordmark "PrimeStreet" *is* the logo: Bricolage Grotesque ExtraBold, tracking −4.5%, no symbol. Component: `Wordmark` (`on-black` = yellow on black, `on-yellow` = black on yellow, `on-white`, `white-on-black`).
- **PS mark:** yellow rounded square + heavy black strokes (geometry in `src/lib/brand.ts`, pure strokes → no font dependency). Verified legible at 16/32/48/64/128/512px. Generated by `npm run icons` into `src/app/icon.svg|png`, `apple-icon.png`, `public/icons/ps-*.png`, `public/brand/ps-on-{yellow,black,white}.svg`. Used for favicon, PWA icon (manifest), social avatars, podcast/YouTube avatar.

## Typography
Display: Bricolage Grotesque 600–800 (headings, wordmark). Body/UI: Inter.

## Components
- **Buttons:** primary = yellow bg + black text (hover `-hover`, active `-dark`); dark = black bg; outline = 2px black. Min height 48px.
- **Links:** body links black with a yellow 3px underline (`.prose-ps a`). Never yellow-on-white.
- **Focus:** 3px black outline + 6px yellow halo on light; yellow outline on dark (`.on-dark`).
- **Status** (Unclaimed / Verified / Sample / Sponsored) always uses text + icon + border, never colour alone.
- **Light/dark:** site is light-mode editorial; header, footer, hero, podcast and profile heads are black sections ("dark moments"). No user-toggled dark mode yet (tracked in todo).

## Social / podcast / video rules
Avatar = PS on yellow. Covers/thumbnails: yellow field + black type, or black field + yellow type, with the wordmark. Same `#FFD400` everywhere — never eyeball-match.
